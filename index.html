إنشاء / انضمام

إضافة فواتير

ارفع صورة أو أكتر أو ملفات PDF لفواتير متعددة دفعة واحدة، وسنحاول نقرأ الموردين والمنتجات والأسعار والكميات تلقائيًا لكل فاتورة. لو رفعت ملف PDF فيه كذا صفحة، هنتعامل مع كل صفحة كفاتورة منفصلة. راجع البيانات قبل الحفظ.

اضغط لاختيار صورة أو PDF واحد أو أكتر للفواتير

راجع اتجاه كل صورة قبل التحليل — لو صورة مقلوبة أو مايلة، دوّرها بالزراير عشان نضمن قراءة صح. ده بيمنع أخطاء كبيرة في البيانات المستخرجة.

إعدادات الموردين

حدد جهة ونسبة ضريبة افتراضية لكل مورد. أي فاتورة جديدة منه هتاخد نفس الإعدادات تلقائيًا (تقدر تغيّرها لفاتورة معيّنة وقت الإضافة). المنتج اللي محتاج جهة مختلفة، حدّدها من تفاصيله وهتتقدّم على جهة المورد.

دمج موردين متكررين

أو حدد الأسماء بنفسك، واكتب الاسم النهائي اللي عايزه.

مراجعة وتعديل قبل الدمج

راجع كل سجل سعر تحت. عدّل السعر أو الكمية أو الوحدة لو فيه غلط قبل ما تأكّد — سعر الوحدة بيتحدّث قدامك أول بأول. ولو صف معيّن صنف مختلف (عبوة تانية مثلًا) غيّر اسمه في عمود "الاسم".

كل الأسعار المسجّلة

استيراد بيانات

لو الشبكة عندك بتمنع التحليل التلقائي للصور، ابعتلي صور الفواتير في المحادثة عشان أقرأها وأجهزلك البيانات، وبعدين الصق الناتج هنا. الصيغة المطلوبة: مصفوفة JSON فيها فاتورة أو أكتر، كل فاتورة فيها متجر وتاريخ وأصناف.

رفع ملف Excel

اختر ملف Excel (الشيت الأول: المورد، التاريخ، رقم الفاتورة، نوع الدفع، نسبة الضريبة، الصنف، الباركود، الكمية، الوحدة، السعر، الوجهة). هيتقرأ ويتحول تلقائياً، وبعدها اضغط "استيراد".

أصناف المورد

اكتب الأصناف اللي المورد ده بيبيعها فعلًا. الاسم الغريب بيتقترح له الصنف اللي اسمه قريب، أو اللي سعر الوحدة بتاعه نفس السعر. أي اسم غريب اتسجل (زي "كبده" أو "مروحه" بدل "فروج كامل") بيظهر بالأحمر، وتختار يتحوّل لأنهي صنف. ومن بعدها، الفواتير الجديدة بتتصلّح لوحدها.
