إضافة فواتير

ارفع صورة أو أكتر أو ملفات PDF لفواتير متعددة دفعة واحدة، وسنحاول نقرأ الموردين والمنتجات والأسعار والكميات تلقائيًا لكل فاتورة. لو رفعت ملف PDF فيه كذا صفحة، هنتعامل مع كل صفحة كفاتورة منفصلة. راجع البيانات قبل الحفظ.

اضغط لاختيار صورة أو PDF واحد أو أكتر للفواتير

راجع اتجاه كل صورة قبل التحليل — لو صورة مقلوبة أو مايلة، دوّرها بالزراير عشان نضمن قراءة صح. ده بيمنع أخطاء كبيرة في البيانات المستخرجة.

إعدادات الموردين

حدد جهة ونسبة ضريبة افتراضية لكل مورد. أي فاتورة جديدة منه هتاخد نفس الإعدادات تلقائيًا (تقدر تغيّرها لفاتورة معيّنة وقت الإضافة). المنتج اللي محتاج جهة مختلفة، حدّدها من تفاصيله وهتتقدّم على جهة المورد.

دمج موردين متكررين

حدد الأسماء اللي هي في الحقيقة نفس المورد، واكتب الاسم النهائي اللي عايزه.

مراجعة وتعديل قبل الدمج

راجع كل سجل سعر تحت. عدّل السعر أو الكمية أو الوحدة لو فيه غلط قبل ما تأكّد — سعر الوحدة بيتحدّث قدامك أول بأول. الاسم النهائي هيتطبق على كل الصفوف.
